# Get ready for the hackathon

Build Agents That Remember takes place October 16 to 18 at 42 Paris. [Register and check the event details on Luma](https://luma.com/bnre6nou).

## 1. Arrange participant access

The 30-day Screenpipe Business offer is being prepared. Organizers will share the participant page once activation is verified. Access runs from the day you claim, with no credit card or automatic paid renewal. If you already have access, keep using it and contact the organizers if needed. External AI providers may charge separately.

## 2. Install and try a small capture

[Download Screenpipe](https://screenpipe.com/download), sign in with the account you used to claim access, and follow the app's permission prompts. Try it before the weekend so you have useful work history to build with. Record a small task you are comfortable using, then check that you can find it in the app. See [local data setup](local-data.md) for the API connection and troubleshooting.

## 3. Run the fictional sample

You can start immediately without Screenpipe history, a subscription or an AI key. Install [Bun](https://bun.sh/docs/installation) 1.3 or newer, then:

```sh
git clone https://github.com/screenpipe/hackathon-starter.git
cd hackathon-starter
bun run demo
bun start
```

Open http://localhost:4242 to review the sample workflow. Return to the [nine projects and track suggestions](../README.md#choose-a-useful-problem) to choose your starting point.

## 4. Join the community and prepare your demo

Use the Discord invitation in your organizer email and follow the `#hackathon-access` instructions to get the participant role. Ask the organizers for help if you cannot find the invitation. [Luma](https://luma.com/bnre6nou) has the host contact and current event details.

Use the [submission checklist](submission.md) to prepare your project. The organizers will confirm the final destination and deadline.
